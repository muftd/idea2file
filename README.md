# idea2file

输入一句自然语言想法 → 输出结构化 Markdown 笔记。

## 快速开始
1. 克隆仓库：`git clone <repo-url> && cd idea2file`
2. 安装依赖：`pip install -r requirements.txt`
3. 运行项目：`python main.py`
4. 在提示中输入一句想法，等待自动生成对应的文件。

## 两种运行模式
- **离线演示模式**：不需要外部大模型服务，使用内置示例响应快速展示产品体验。
- **AI 模式**：在运行前设置 `OPENAI_API_KEY` 环境变量，系统会自动调用在线模型生成高质量的笔记内容。

## 命名规则
- 系统会根据用户输入的主题自动生成语义化文件名。
- 若生成的文件名与现有文件冲突，会自动附加时间戳或序号，以确保不重复覆盖。

## 开发者笔记
为了便于切换不同的大模型供应商，并支持完全离线的演示场景，项目将 API Key 的读取逻辑与业务处理流程解耦。这样可以在不改动核心生成逻辑的前提下，自由替换调用端或模拟器。
